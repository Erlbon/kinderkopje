Public beta database

A SQLite file anyone can download and open in any SQLite tool: the rankings and the point-scoring results collected so far, with races (internal and external names), links, countries and continents. It holds names, nations, rider ages, places, points, team names, race names, race links and race facts: no layout, no photos. This is a beta: not every race is in it yet.
