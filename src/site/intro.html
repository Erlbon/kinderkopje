Pelotonic - The R Peloton Database Project

Statement of intent

IntroThreadsTeams and pointsRace resultsData

The raison d'etre of this project is being an AI-assisted hub for collecting information from reddit/r/peloton, UCI.org and other sources (see the sources below) to assist creating future content for /r/peloton.

The tasks we have created this project for are:

  • Automatic Race Thread Generation
  • Automatic Race Statistics (f.e. 5x5, most likely riders to win)
  • Automatic Team Statistics (current vs. previous year - pointshaul per race/month)

Sources

The links we have found useful. Everything is opened by a person in a browser; the tool never fetches pages from these sites on its own, except Wikipedia and Wikidata through their public APIs.
  • r/peloton: where the threads are posted, and the old threads the tool learns from.
  • UCI.org: competition hubs, calendars and race pages.
  • UCI DataRide, road results: the competition list, with each race's class, dates and results. The capture bookmark reads these pages.
  • UCI DataRide, rankings: the UCI World Ranking, including the team ranking.
  • INRNG calendar: the race calendar, also as an iCal feed for the season draft.
  • INRNG: the UCI points system since 2024: how points are awarded.
  • ProCyclingStats, race calendar: read by hand only; the site does not allow automated access.
  • FirstCycling: start lists and results, read by hand only; no automated access.
  • Wikipedia, UCI WorldTeam: which teams are WorldTeams and ProTeams each season, and the stage tables of the Grand Tours.
  • Wikidata: race homepages and Wikipedia links.
